# Amazon Orders Exporter

## Table of Contents

- [Purpose](#purpose)
- [Public pages](#public-pages)
- [Privacy](#privacy)

## Purpose

Personal analysis of Amazon order history in Google Sheets. The current workflow
uses the `amazon-orders` CLI and an authorized Google account.

## Public pages

The `docs/` directory contains the public OAuth homepage, privacy notice, and
terms. Publish only these pages through GitHub Pages.

## Privacy

Keep order exports, session cookies, OAuth credentials, and personal account
configuration outside this repository.
